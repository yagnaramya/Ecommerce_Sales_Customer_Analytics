**# E-Commerce Sales \& Customer Analytics**



**## 📊 Project Overview**



**This Power BI project analyzes e-commerce sales, customer behavior, product performance, profitability, and returns.**



**The dashboard transforms raw transactional data into interactive business insights that help understand revenue performance, customer segments, product contribution, profitability, and return patterns.**



**## 🎯 Business Objectives**



**\* Analyze overall sales and profitability performance**

**\* Understand customer behavior and customer segments**

**\* Identify high-performing products and categories**

**\* Track monthly revenue and profit trends**

**\* Analyze product returns and return reasons**

**\* Compare sales performance across categories**

**\* Build an interactive dashboard using Power BI**



**## 🗂️ Dataset**



**The project uses an e-commerce dataset containing information related to:**



**\* Customers**

**\* Products**

**\* Orders**

**\* Order Details**

**\* Returns**



**The data was modeled in Power BI using relationships between the relevant tables.**
